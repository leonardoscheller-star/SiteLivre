# Site sobre meu amigos
Esse site foi desenvolvido com o objetivo de falar sobre as minhas amizades, ele é um blog curto com 4 posts, sendo todos eles relacionados aos meus amigos (tiveram amigos que não estão presentes nas fotos), ele possui 4 imagens e 1 vídeo, para faze-lo utilizei o gemini como auxílio para corrigir erros. Esse site faz parte de um trabalho da Professora Tatyanne Royek Lazier do Colégio de Aplicação Pedagogica da UEM. Todos os conteúdos são de minha autoria.
